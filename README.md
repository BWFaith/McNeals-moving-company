# McNeal's Moving & Logistics: Website

Static website (HTML, CSS, JavaScript). No build step. Open `index.html` or upload the whole folder to any host (Netlify, Vercel, cPanel, GitHub Pages).

## Pages
index, about, services, process, gallery, areas, faq, booking (quote calculator + booking), contact.
The header, footer, page banner and bottom call-to-action are generated by `js/main.js`, so edit navigation and footer text there.

## 1. Replace the placeholder photos
Everything in `assets/img/` ending in `.svg` is a placeholder (services, gallery, before/after, areas, team).
Save your photo with the same name but `.jpg`, then change the extension in the HTML, or just search and replace `.svg` with `.jpg` for that file name.
Before/after pairs: `ba1-before` / `ba1-after`, `ba2-before` / `ba2-after`. Add gallery photos by copying a `<figure>` in `gallery.html`.
Testimonials on the home page are labeled "Sample review". Replace them with real customer reviews before launch.

## 2. Make booking emails work (client copy + owner copy)
The site uses EmailJS (free tier) so no server is needed. Each booking sends the quote to the customer and a second copy to the owner.
1. Create an account at emailjs.com and add an Email Service (connect Gmail: Mcnealonthemove@gmail.com).
2. Create one Email Template with: To Email `{{to_email}}`, Reply-To `{{reply_to}}`, Subject `{{subject}}`, Content `{{message}}`.
3. Copy your Public Key, Service ID and Template ID into `CFG.emailjs` at the top of `js/main.js`.
Until this is filled in, the form falls back to opening the customer's email app with the quote, copying the owner.
Also confirm the owner email spelling in `CFG.ownerEmail` (the Facebook page shows two spellings: mcnealonthemove and mcneilonthemove).

## 3. Edit prices
All quote-calculator numbers are in `CFG` at the top of `js/main.js`: hourly rates ($110 for 2 movers comes from your ads; the 3 and 4 mover rates are placeholders), truck fee, mileage, stairs, TV mounting ($75), add-ons.
Home sizes and hours are in the `<select name="size">` in `booking.html` (`data-h` = base hours).

## 4. Before launch
Add your license/insurance line in the footer, real social links, opening hours, and a favicon. Test the booking form once with your own email.
